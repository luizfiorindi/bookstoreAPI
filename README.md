# Bookstore API

API para gerenciamento de livros, desenvolvida com ASP.NET Core e .NET 8.

Neste momento, o projeto está em desenvolvimento inicial. A API terá como objetivo permitir o cadastro e o gerenciamento das informações dos livros.

## Funcionalidades previstas

A API deverá permitir:

- Criar um livro;
- Visualizar todos os livros cadastrados;
- Visualizar um livro específico;
- Editar as informações de um livro;
- Excluir um livro.

## Tecnologias

- .NET 8;
- ASP.NET Core Web API;
- Swagger/OpenAPI para documentação e testes da API.

## Status do projeto

As regras de negócio, os endpoints, os modelos de dados e as demais informações de uso serão adicionados e atualizados conforme o desenvolvimento do projeto avançar.
